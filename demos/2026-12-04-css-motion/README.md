# CSS だけで作る、アプリのような動き（デモ）

View Transitions・スクロール連動アニメーション・`:has()`・コンテナクエリのデモです。ライブラリは使っていません。

## 開き方

ファイルを直接開く（`file://`）と、デモは動きません（JavaScript のモジュールが読み込めないため）。このフォルダをローカルのサーバーから開いてください。

```bash
npx serve .
```

## ページ

| ページ | 内容 |
| --- | --- |
| `index.html` → `detail.html` | View Transitions：ページ内の並べ替え、カードから詳細ページへの遷移 |
| `scroll.html` | スクロール連動：読了バー、フェードイン、パララックス、横送り |
| `has.html` | `:has()` の選択カードとフォーム、コンテナクエリのプロフィール |

各ページの右上にある **「仕組みを見る」** をオンにすると、裏で起きていることを表示します（ページをまたいでオンのまま）。

## 対応ブラウザ

Chrome で確認しています。Safari・Firefox はバージョンによって一部の演出が動きません。その場合は、動きのない普通の表示になります。
