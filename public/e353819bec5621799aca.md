# Keyof型演算子
### keyによる警告
key情報で型を制限します。
```ts
type Point = { x: number; y: number };
type P = keyof Point;
//OK
const ok:P = "x";
//NG
const ng:P = "a";
```

# Typeof 型演算子
### 型情報の返還
typeofの後に記述した内容から型を返還します。
```ts
// string
console.log(typeof "Hello world");
```

# インデックスアクセスタイプ
### オブジェクト内から型情報を取得
```ts
type Person = { age: number; name: string; alive: boolean };
// number
type Age = Person["age"];
// UnionType
type I1 = Person["age" | "name"];
// keyofによる取得
type I2 = Person[keyof Person];
```
