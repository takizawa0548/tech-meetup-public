# stateの保持とリセット

## stateはレンダーツリーの位置に結びついている
Reactはstateを保持し、レンダーツリーに沿ってstateを管理します。
コンポーネントが破棄されるときに紐づいたstateも破棄されます。

### 同じ位置のコンポーネントならstateは保持される
下記の場合、タグは分かれているがレンダーツリー上同一なものとみなされstateは保持される。
```react
{isFancy ? (
    <Counter isFancy={true} /> 
) : (
    <Counter isFancy={false} /> 
)}
```
下記の構成でもレンダーツリーが同じのためstateは保持される
```react
if (isFancy) {
    return (
      <div>
        <Counter isFancy={true} />
        <label>
          <input
            type="checkbox"
            checked={isFancy}
            onChange={e => {
              setIsFancy(e.target.checked)
            }}
          />
          Use fancy styling
        </label>
      </div>
    );
  }
  return (
    <div>
      <Counter isFancy={false} />
      <label>
        <input
          type="checkbox"
          checked={isFancy}
          onChange={e => {
            setIsFancy(e.target.checked)
          }}
        />
        Use fancy styling
      </label>
    </div>
  );
}
```

上記の点から、
・同じタグ構成であればstateは保持される。
・少しでも構成が違うと、表示は同じでもコンポーネントが切り替わったり表示されなくなればstateは破棄される


### stateを保持させたくない場合
下記の状態だと、Counterコンポーネントのレンダーツリーが一致するためstateは保持され続ける。
```react
<div>
  {isPlayerA ? (
    <Counter person="Taylor" />
  ) : (
    <Counter person="Sarah" />
  )}
```
コンポーネントのstateが切り替わるルールは二つ
１.コンポーネントを異なる位置でレンダーする
2.key を使って各コンポーネントに明示的な識別子を付与する

#### コンポーネントを異なる位置でレンダー
タグを変えるだけではなく、レンダー時に一時的にタグの表示を消すことで、stateの破棄も可能。
分離して配置しているとstateが破棄されるとも取れる。
```react
    <div>
      {isPlayerA ?
        <Counter person="Taylor" />
      }
      {!isPlayerA &&
        <Counter person="Sarah" />
      }
```

#### key を使って各コンポーネントに明示的な識別子を付与する
keyを使うと識別子になり、コンポーネントのstateが破棄される。関連のあるコンポーネントにkeyを設定することで値が切り替わった時にコンポーネントのstateを破棄するようコントロールできる。

```react
  return (
    <div>
      {isPlayerA ? (
        <Counter key="Taylor" person="Taylor" />
      ) : (
        <Counter key="Sarah" person="Sarah" />
      )}
```
