# コンテキスト
#### vars
カスタムの構成変数を呼び出せる
設定されていない場合、変数を参照するコンテキストの戻り値は空の文字列。

設定方法はこの記事を参照

https://zenn.dev/kou_pg_0131/articles/gh-actions-configurations-variables

#### job
現在実行中のジョブに関する情報を取得できる
ジョブコンテナのIDや内部で動作しているサービス情報。

#### jobs
job名から結果や内容を取得できる

#### steps
job内のstep結果や内容を取得できる

#### runner
runs-on: ubuntu-latestの内部情報が見れる

#### secrets
Settingから指定する。特別値を編集するなどしなければ、ログや出力はマスクされ値が表示されることはない。
![スクリーンショット 2024-06-30 13.37.54.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/fc05105b-d82d-a4a3-86cc-3915bb617361.png)

#### strategy
jobのトータルや現在のジョブ数、実効結果の成否を表示できる

#### matrix
マトリックスプロパティを参考に全てのパターンのジョブを実行

```yml
build:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest]
        node: [14, 16]
```
![スクリーンショット 2024-06-30 13.54.16.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/6672f15c-9e50-50a5-e0ec-a1abfa88a8bf.png)

#### needs
指定した値が取れるまで処理を待つことができる。
下記の場合、build処理を待ってから実行される
```yml
build:
    runs-on: ubuntu-latest
    outputs:
      build_id: ${{ steps.build_step.outputs.build_id }}
    steps:
      - name: Build
        id: build_step
        run: echo "build_id=$RANDOM" >> $GITHUB_OUTPUT
deploy:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - run: echo "Deploying build ${{ needs.build.outputs.build_id }}"
```

## nameの表示場所
「Build and deploy」という名前でグルーピングされる
```yml
name: Build and deploy
on: push

jobs:
  build:
...
```
