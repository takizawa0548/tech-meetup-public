# 実際にやってみた
単純でした。ローカルでNext.jsを立ち上げれば、特に修正もなくいけるはず。
API呼び出しはginxなのでそこで捌いてくれるでしょう。（フラグ）

起動します。
コンテナ起動
```bash
docker compose up 
```
ローカルのNext.js起動
```bash
cd web
npm run dev
```
動いている確認します。

http://localhost:3000

CORSエラーを返されました。同一オリジンポリシーに引っかかったようです。

![スクリーンショット 2024-02-29 12.34.44.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/0b446e4c-18ba-20dd-999d-373e93b50356.png)


https://blog.mamansoft.net/2020/01/21/cors-with-nginx-from-browser/

ベストプラクティスがあるかと思いますが、上記の記事を参考にNginxのconfファイルにヘッダー設定を追加します。

```conf
       add_header Access-Control-Allow-Origin *;
```

```conf
server {
    listen       80;
    server_name  localhost;

    location / {
    root   /usr/share/nginx/html;
    index  index.html index.htm;
    }

    location /Hello {
       root /var/www/src/webroot/index.php;
       add_header Access-Control-Allow-Origin *;
       fastcgi_param HTTP_PROXY "";
       fastcgi_pass api:9000;
       include fastcgi_params;
    }
}
```

再起動して確認しましょう。
Next.jsからAPI呼び出しができていることも確認できました。
