# Wire in data
Reduxなど、データストアを確認するといった連携は単純にはできないので、storiesファイルでReduxを用意し作成する。
```jsx
const Mockstore = ({ taskboxState, children }) => (
  <Provider
    store=...
  >
    {children}
  </Provider>
);
};
```
テストケースにラップするdecoratorsを記述する。
```jsx
export const Default = {
  decorators: [
    (story) => <Mockstore taskboxState={MockedState}>{story()}</Mockstore>,
  ],
};
```

export defaultにMockedStateコンポーネントを除外することを記述すると、StoryBookに表示されなくなる。
ちなみにdecoratorsは、すべてのStoryにスタイルをラップする
```jsx
export default {
  decorators: [(story) => <div style={{ margin: '3rem' }}>{story()}</div>],
  excludeStories: /.*MockedState$/,
};
```

# Construct a screen
msw(Mock Service Worker)を使用して、モックデータを返してくれるAPIを作成する。

```bash
npm install msw --save-dev
npx msw init public/ --save
```

storyのpreviewファイルでimport
```jsx
import { initialize, mswLoader } from 'msw-storybook-addon';
```

mswの初期化
```jsx
initialize();
```

storybookでモックしたAPIリクエストを利用できるようにする記述
```jsx
loaders: [mswLoader],
```

モックデータで正常画面とエラー画面の動作を確認しましょう。
