# 関数の詳細
### 不要なジェネリクス
型指定のバリエーションが増えてくると不要な指定も増えてしまうので複雑にならないように注意する。
```ts
// extendsしなくて良い
function greet<Str extends string>(s: Str) {
  console.log("Hello, " + s);
}
// 単純に指定しても問題ない
function greet(s: string) {
  console.log("Hello, " + s);
}
```
### オーバーロード記述よりもUnionTypeやジェネリクス
TypeScriptのオーバーロードは事前に複数の関数宣言を用意し最下部に実装を記述します。
慣れもあると思いますが、UnionTypeやジェネリクスでできるのであれば優先して使用する方がいいかもしれません。
```ts
// オーバーロード
function len(s: string): number;
function len(arr: any[]): number;
function len(x: any) {
  return x.length;
}
// UnionType
function len(x: any[] | string) {
  return x.length;
}
```
### Functionよりも具体的な()=>void
下記の書き方は、どんな関数でも受け取る状態です。
```ts
function doSomething(f: Function) {
  return f(1, 2, 3);
}
```

具体的に引数の型が確定しているのであればアロー関数で記述しましょう。
```ts
function doSomething(f: (a:number,b:number,c:number) => void) {
  return f(1, 2, 3);
}
```

### スプレット構文とメソッド引数
下記のメソッドは引数が二つであることを求めているため、配列数が固定でもTypeScriptが推測できず警告されます。

```ts
const args = [8, 5];
const angle = Math.atan2(...args);
```
as constを使用してTypeを固めましょう。

```ts
const args = [8, 5] as const;
const angle = Math.atan2(...args);
```

### voidの返し値
voidは、値を無視するという意味で定義されますが実際は値を返します。
下記の場合でも警告されないので注意しましょう。

```ts
type voidFunc = () => void;
 
const f1: voidFunc = () => {
  return 1;
};
 
const f2: voidFunc = () => true;
 
const f3: voidFunc = function () {
  return true;
};

console.log(f1());
```
