# コンポーネント宣言
・コンポーネントは、マークアップ（HTML)を返すJavaScript関数。UIの部品を表す再利用可能なコード。
・①アロー関数（関数式）、②関数宣言でコンポーネントを作成する。

```React
// ①アロー関数（関数式）
const コンポーネント名 = () => {}
// ②関数宣言
function コンポーネント名() {} 
```
・頭文字が大文字でコンポーネント、小文字でJavaScriptとして判別される。
※一部例外でカスタムフック名内でもuseStateが使えます（useCompとか)
```React
// 頭大文字
const Component = () => {
// タグとして扱える。内部でuseStateとか使える。
}
// 頭小文字
const javascript = () => {
// 関数や値として活用できる。
}
```
# 外部ファイルから使用したい時
・export
　外部ファイルから使用を可能にする。
・default
　このファイルのメイン関数であることを宣言する。
```React
// defaultの書き方
export default function Test{
    return <div></div>
}
// constの場合は、別行で宣言
const Test{
    return <div></div>
}
export default Test;
// constでdefaultがいらない場合
export const Test{
    return <div></div>
}
```
# コンポーネントをタグとして使用する
・コンポーネントの場合、マークアップのReturn内ではタグとして使用できる。
```React
const Component = () => {}

export const App = () => {
    return (
        <Component />
    );
};
```
・Return内のタグはタグひとつで囲む必要がある。
```React
return (
    //二つはNG
    <Component />
    <Component />
);
```
```React
return (
    //空タグで一つにまとめる
    <>
        <Component />
        <Component />
    </>
);
```
## JavaScriptも一緒に書くとき
・return内でも{}を使えばJavaScriptの記述は可能
```React
function testAlert() {
    alert('関数');
}
return (
    <>
        <Component />
        <Component />
        {/*下記の書き方だとonClickなどイベントに書いててもレンダリング完了後に即時実行される*/}
        {alert('直接')}
        {testAlert()}
    </>
);
```

# Propsを渡す
propsに値、state、関数を渡すことができる。
{}内で、関数（）と記述すると即時実行になるのでアロー関数を利用することで防ぐ。
イベントを処理するハンドラ関数は、「handle~」で命名する
onClickなどイベントを表すものは、「on~」で命名する
```React
import { useState } from 'react';
function Square({ value, onAlertClick, onAllowClick }) {
  return <button className="square" onClick={onAlertClick ? () => onAlertClick("click") : onAllowClick}>{value}</button>;
}
export default function Board() {
  const [value,setValue] = useState("1");
  //イベントを処理するハンドラ関数は、handle~で命名する
  function handleClick(text){
      return alert(text);
  }
  return (
    <>
      <div className="board-row">
        {/*stateと関数が渡される。*/}
        <Square value={value} onAlertClick={handleClick} />
        {/*value222は存在しないため値が渡されない*/}
        <Square value222="2" /> 
        {/*アロー関数で引数をつけて渡す*/}
        <Square value="3" onAllowClick={() => alert("allow")}/>
      </div>
    </>
  );
}
```
