# 導入した拡張機能や設定一覧

## 設定


#### setting Sync
　他のPCと設定を共有できるようになります！パソコンの入れ替えで度々同じ設定にするのは面倒だと思うのでこれがあると便利。Githubで登録しました。

 
## 拡張機能

#### GitHub Copilot
自然言語でHTMLの雛形作ってとか言うと作ってくれるし、言う前からコードを提案してくれるため有料だが設定
![スクリーンショット 2024-03-17 15.42.07.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/5fe27ca2-1a9d-b99c-53ce-ec74bb48f3f9.png)

#### Prettier
ソースコードの自動整形。インデントとか綺麗にしてくれる。

![スクリーンショット 2024-03-17 15.42.35.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/8bae610b-6164-45e4-2875-d9fef0d4c2e0.png)

#### Live Server
HTMLの修正結果がリアルタイムで反映される。ホットリロードみたいなもの。
![スクリーンショット 2024-03-17 15.43.14.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/c52bfde2-6ff4-6c03-18b8-7790491e6840.png)

#### Image preview
イメージ画像をコード上でプレビュー表示できる。
![スクリーンショット 2024-03-17 15.47.04.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/b343a2d2-72ec-7ed2-5b84-27a5fb6c2362.png)

#### HTML CSS Support
CSSファイルに定義しているid,classを入力候補として表示してくれる。
![スクリーンショット 2024-03-17 15.52.30.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/5e899994-3a31-11f9-f7a8-e6f82c1aa392.png)

#### Color Highlight
16進数で定義した色を強調表示する。
![スクリーンショット 2024-03-17 15.56.08.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/6a7c6345-8c54-cc39-d3f2-7d64710c7f8f.png)

#### Highlight Matching Tag
開始タグと閉じタグを強調表示する。
![スクリーンショット 2024-03-17 15.57.45.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/1d2832c6-abc7-e8d2-3515-fd4f6fb27c2c.png)

#### Intellisense
プログラミング言語ごとにあり、コード補完でメソッドを探したりできる。
PHPは、Intelephenseを入れた。
![スクリーンショット 2024-03-17 16.00.07.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/37a134a2-4a8c-7e8f-3542-c3bf6416db21.png)

#### snippets
プログラミング言語ごとの書き方を補完できる。
「@category:snippets」で検索

![スクリーンショット 2024-03-17 16.07.45.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/01b96a81-200e-d4cc-0ed4-a1b73d54bbaa.png)

#### debuggers
JavaScriptに変換される言語は標準で対応されているがそれ以外は、「@category:"debuggers"」で検索して取得
PHPも入れてみたかったがXDEBUGの設定が必要だったため保留中

![スクリーンショット 2024-03-17 16.43.51.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/0ed15eb9-b577-3886-00f0-442fade74f1b.png)
