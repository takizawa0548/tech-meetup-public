
![スクリーンショット 2024-02-17 18.44.23.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/2ee5d45d-8c5c-32a4-08ff-5b9d85d9fbe3.png)

記載されているコマンドを実行してみます。
※<strong>[ユーザー名]</strong>は自分のを入れてください。
```
(echo; echo 'eval "$(/opt/homebrew/bin/brew shellenv)"') >> /Users/<strong>[ユーザー名]</strong>/.zprofile
```
特に反応なし。まぁそんなもんかという気分で次のコマンド！
```
eval "$(/opt/homebrew/bin/brew shellenv)"
```
改めて下記のコマンドを実行してみる。
```
brew help
```
動いたー！

# Homebrewでインストールしてみる
色々入れているのとnodebrewは次回にやりたいので、今回はMozilla Firefoxを入れてみようかと思います。

まずは下記のコマンドでインストールできるか検索！（ウェブでも検索しました）
```
brew search firefox
```
FormulaeとCasksであるみたい。この二つの意味はなんでしょう？

![スクリーンショット 2024-02-17 19.17.30.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/0efb4d6e-ac04-d21d-fa8d-5442f5c13878.png)

っていうことで調べてみると下記の通りでした。

<dl>
  <dt>Formulae</dt>
  <dd>開発者向けのツールやライブラリ、nodebrewはこっち</dd>
  <dt>Casks</dt>
  <dd>GUIアプリケーション、Google ChromeやMozilla Firefoxはこっち</dd>
</dl>


念のため、検索するとコマンドコピーできる模様。便利ですね。

https://formulae.brew.sh/cask/firefox

コマンド実行します。

```
brew install --cask firefox
```
無事成功しました！

![スクリーンショット 2024-02-17 19.25.10.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/c90335b4-ec3d-1974-6215-f96520167cf7.png)
