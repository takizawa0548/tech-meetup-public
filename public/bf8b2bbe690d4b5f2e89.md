# 今回の目的
本は読んでるけど、どれくらい読んでいるだろう、どんな本だったけ？というのと記録したい、でも書いていると読むのに時間がかかるというのもあり、一言記事を書いてみることにしました。

# 今月読んだ本
### Visual Studio Code完全入門　Webクリエイター&エンジニアの作業がはかどる新世代エディターの操り方

https://book.impress.co.jp/books/1121101051

拡張機能周りで便利なものがまとまっていて読み応えがありました。Intelligenceが各プログラミング言語で用意されているのも知らなかったので勉強になりました。

### React Angular Vueをスムーズに修得するための最新フロントエンド技術入門

https://bookplus.nikkei.com/atcl/catalog/21/S70210/

いままでリクエスト＆レスポンスで画面をすべて再描画する従来型Webで開発していたので、モダンWebへの変遷を学べたのは大きかったです。

### 「やりたいこと」も「やるべきこと」も全部できる！ 続ける思考

https://honto.jp/netstore/pd-book_32953053.html

継続を趣味という著者の考えに共感しました。というより継続を趣味と言っていいんだという新しい考え方をもらった気がします。
また無理に続けようとすると続かないというところと共感でき、自分の考えが整理できました。

### React Hooks 入門: フックの基礎や使い所をしっかり理解して使いこなす

https://bookmeter.com/books/16795497

Reactを触って間もなかったのでHooksを敬遠してましたが、この本のおかげでだいたいの内容を整理することができました。
