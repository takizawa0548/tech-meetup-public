### Type Assertions
asや<>を使用して型を限定的にできる。
```ts
//HTMLElement | nullが本来ついているが、HTMLCanvasElementの型に限定できる。
const myCanvas = document.getElementById("main_canvas") as HTMLCanvasElement;
const myCanvas = <HTMLCanvasElement>document.getElementById("main_canvas");
```

#### 型注釈との違いは？
型注釈は、変数に対して型を限定します。変数の型とは違う型を入れるとコンパイルエラーになります。
```ts
const x:string = "hello";
```
型アサーションは、値の型を限定します。推論でstringにせず宣言的に行います。
```ts
const x = "hello" as string;
```

### Literal Types
一つだけだと意味はあまりないがunionTypeと組み合わせると効果を発揮する
・一つだけ
```ts
const obj:{counter:0} = { counter: 0 };
```
・複数の場合
```ts
// alignmentはleft,right,centerのみ
function printText(s: string, alignment: "left" | "right" | "center") {
  // ...
}
// 戻り値にも対応できる
compare(a: string, b: string): -1 | 0 | 1 
// リテラルと非リテラルを組み合わせることもできる
function configure(x: Options | "auto") {
  // ...
}
```

### オブジェクトの推論
下記の場合、reqは{url:string, method:string}と推論され、req.method呼び出しでTypeScriptエラーになります。

```ts
declare function handleRequest(url: string, method: "GET" | "POST"): void;
 
const req = { url: "https://example.com", method: "GET" };
handleRequest(req.url, req.method);
```

型アサーションで固定するか、定数アサーションでそのものをtype化する必要があります。
・型アサーション
```ts
// Change 1:
const req = { url: "https://example.com", method: "GET" as "GET" };
// Change 2
handleRequest(req.url, req.method as "GET");
```
・定数アサーション
抽象的なstringではなく、具体的な値がLiteral Typesとして割り当てられます。
```ts
const req = { url: "https://example.com", method: "GET" } as const;
handleRequest(req.url, req.method);
```
reqのtypeは以下のようになります
```ts
const req: {
  readonly url: "https://example.com";
  readonly method: "GET";
}
```

#### filterでは型ガード
filterでまとめるものがstringのみである場合に型アサーションを使えるが、型ガードの方がより確実に型を狭めることができます。
```ts
const items: (string | undefined)[] = ['str', undefined]
// filter時にstringに狭める
const stringItems = items.filter((item): item is string => typeof item == 'string')
// 型安全がないため非推奨
const stringItems = items.filter(item => typeof item === 'string') as string[]
const upperString = stringItems.map(item => item.toUpperCase)
```
