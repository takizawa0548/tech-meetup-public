## イベントハンドラ
イベントハンドラは、onClickのようなクリックへの反応とか。
イベントハンドラ関数の命名は、「handle+イベントの名称」が一般的である。
例：クリックなら「handleClick」、マウスポインタが入ってきた時「handleMouseEnter」

```react
export default function Button() {
    //イベントハンドラ(handle〜）
    function handleClick() {
        return alert("test");
    }
  return (
    <>
        {/*OK:渡すことでイベントハンドラ関数がクリックに反応する*/}
        <button onClick={handleClick}>ボタン</button>
        {/*NG：()があるとレンダー後すぐに発火する*/}
        <button onClick={handleClick()}>ボタン</button>
        {/*アロー関数で定義するのも可能*/}
        <button onClick={() => {alert('test2')}}>ボタン</button>
    </>
  );
}
```

## イベントハンドラ関数をpropsとして渡す
イベントハンドラのプロップは「on+大文字から始まる好きな名前」で命名する。
```react
// イベントハンドラとchildrenを受け取るボタンタグ
function Button({ onPlay, children}) {
    return (
        <button onClick={onPlay}>
            {children}
        </button>
    );
}
// イベントハンドラ関数
function PlayButton() {
  function handlePlayClick() {
    alert(`test`);
  }

  return (
    {/*イベントハンドラのプロップは「on+好きな名前」で命名*/}
    <Button onPlay={handlePlayClick}>
      Play Movie
    </Button>
  );
}
// デフォルトエクスポート
export default function Toolbar() {
  return (
    <PlayButton/>
  );
}
```

## イベントハンドラの伝播を止める
・e.stopPropagation() 
ツリーの上側（親コンポーネント）のイベントハンドラが発火しないようにする。
下記は、e.stopPropagation() がない場合、子→親の順でアラートが発火する。
```react
function Button({ onClick, children }) {
  return (
    <button onClick={e => {
      e.stopPropagation();
      onClick();
    }}>
      {children}
    </button>
  );
}

export default function Toolbar() {
  return (
    <div className="Toolbar" onClick={() => {
      alert('アラートは出ない');
    }}>
      <Button onClick={() => alert('アラートが出る')}>
        Click
      </Button>
    </div>
  );
}
```
・e.preventDefault() 
イベントがブラウザデフォルトの動作を持っていた場合に、抑制する。
```react
export default function Signup() {
  return (
    <form onSubmit={e => {
      e.preventDefault();
      alert('再描画を防ぐ');
    }}>
      <input />
      <button>Send</button>
    </form>
  );
}
```
