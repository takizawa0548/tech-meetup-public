### onClick={() => signOut()}
関数を下記のように直接渡すと暗黙的にイベントが渡される

```tsx
onClick={signOut}
```

引数が不要な場合、明示的に書く必要がある。
例えばsignOutは引数が任意で指定が入っているため、明示的に書かないとエラーが入る・
```tsx
onClick={() => signOut()}
```

### スクロール判定
addEventListenerで関数を発火する。
アンマウントされた時にクリーンアップ関数を用意する。
```tsx
useEffext(() => {
    const handleScroll = () => {
        if (window.scrollY > TOP_OFFSET){
            setShowBackground(true)
        } else {
            setShowBackground(false)
        }
    }

    window.addEventListener("scroll", handleScroll)

    return () => {
        window.removeEventListener("scroll", handleScroll)
    }
},[])
```

### テーブル情報の変更

https://zenn.dev/thirosue/books/49a4ee418743ed/viewer/57d161

schema.prismaのカラムを修正する
thumbbnailUrl→thumbnailUrl

```js
model Movie {
  id String @id @default(auto()) @map("_id") @db.ObjectId
  title String
  description String
  videoUrl String
  thumbnailUrl String
  genre String
  duration String
}
```
保存し下記コマンドを実行

```bash
npx prisma migrate dev --name fix_thumbnail_url_spelling
```
