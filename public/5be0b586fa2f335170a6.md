# TailWindの知識
### md:text-6xl
画面の幅が768px以上の時、テキストサイズ6xl

### flex flex-col
垂直に並べる

### flex gap-8
小要素間の幅を8pxにする

### group
親要素に定義する、ユーザーイベントが発生した時に小要素で設定した変更が反映される
#### group-hover:cursor-pointer
hoverされたときにマウスポインターのアイコンが変更

### border-transparent
ボーダーを透明にする。設定は適用したが表示したくないときに使用する

### overflow-hidden
親要素の幅を超えたものは非表示にする

### fixed
position: fixed;と同様
画面上に固定する。ヘッダーで固定したい場合など。

### px-4
左右のパディングを1rem（通常16ピクセル）に設定する

### flex-row
水平方向に設定

### transition
CSSの遷移（トランジション）を指定できる

### duration-500
遷移（トランジション）の持続時間を500ミリ秒に設定

### lg:h-7
1024px以上で高さを7pxに変更

# Next.jsの知識
### オブジェクト
単純だがどちらもエラーは返さない。{}をつけると構造が変化してしまうので注意
```tsx
res.status(200).json({currentUser});

res.status(200).json(currentUser);
```

### permanent: false
一時的にリダイレクトが必要な場合（認証が必要な時など）falseにする。
```tsx
        return {
            redirect: {
                destination: '/auth',
                permanent: false,
            }
        }
```
