# 基礎

### 静的型チェック
javaScriptだと実行するまでどちらがエラーになるか分からない。
```js
// 文字列だったら動作する
message.toLowerCase();
// 関数だったら動作する
message();
```
もし下記のように定義していた場合、関数呼び出しでエラーになる。
```js
const message = "hello";
```
これがTypeScriptの場合、記述時点で警告してくれます。
```ts
//Type 'String' has no call signatures.
message();
```

### 存在しないプロパティ名
下記の場合でもTypeScriptなら実行前に警告してくれる。
```ts
const user = {
  name: "Daniel",
  age: 26,
};
user.location;
```
TypeScript
```ts
// Property 'location' does not exist on type '{ name: string; age: number; }'
```
JavaScript
```js
// returns undefined
```

### スペルミス
```ts
// Property 'toLocaleLowercase' does not exist on type '"Hello World!"'.
// Did you mean 'toLocaleLowerCase'?
announcement.toLocaleLowercase();
 
// 正しいスペル
announcement.toLocaleLowerCase();
```

### 関数呼び出しミス
```ts
function flipCoin() {
  // 本来は、Math.random()で呼ばなくてはいけない
  // Operator '<' cannot be applied to types '() => number' and 'number'.
  return Math.random < 0.5;
}
```

### 論理ミス
```ts
const value = Math.random() < 0.5 ? "a" : "b";
if (value !== "a") {
  // ...
} else if (value === "b") {
  // aしか来ないのにbであることを判定しているため
  // This comparison appears to be unintentional because the types '"a"' and '"b"' have no overlap.
}
```

### コード補完
エラー解消を提案するクイックフィックスなど、VSCodeはデフォルトで補完されるよにサポートされてます。

### tsc(TypeScriptのコンパイラ）
tscコマンドはtsファイルをコンパイルしてjsファイルを生成する
```bash
tsc hello.ts
```
エラーがあるまま実行すると下記のようなエラーを出します。
例：引数が二個必要なのに一つ指定で呼び出した場合
```bash
hello.ts:5:3 - error TS2554: Expected 2 arguments, but got 1.

5   greet("Brendan");
    ~~~~~

  hello.ts:1:24
    1 function greet(person, date) {
                             ~~~~
    An argument for 'date' was not provided.


Found 1 error in hello.ts:5
```
