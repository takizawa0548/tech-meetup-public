# TODO to Issueとは
コード内のTODOコメントをIssueに書き出してくれるActionsです。

https://github.com/marketplace/actions/todo-to-issue


![スクリーンショット 2024-10-02 20.56.53.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/51335594-2e69-767a-c78a-5936a050efa6.png)

コードを修正した後に、TODOコメントを消してPUSHするとIssueはcloseされます。
![スクリーンショット 2024-10-02 20.59.27.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/f8043baa-b027-41b0-e50a-4b8ffbda1451.png)

# 設定
GITHUBTOKENに書き込み権限を付与します。

Setings>Actions>General>Workflow permissions
![スクリーンショット 2024-10-02 21.02.22.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/fa3dd737-d457-ad6f-4d93-0f1707f0334a.png)

下記のURLでサポート言語を確認しましょう。

[supported-languages](https://github.com/marketplace/actions/todo-to-issue#supported-languages)

Setupのスニペットをコピペしてワークフローを作成しましょう。

[setup](https://github.com/marketplace/actions/todo-to-issue#setup)

Github Actionsの説明は割愛します。

https://docs.github.com/ja/actions/writing-workflows/quickstart

ステップでIssue createdが出ていれば成功です。
