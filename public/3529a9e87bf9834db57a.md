# reducerは、stateを扱うもう1つの方法
reducerはstateをまとめて更新することができます。

useState から useReducer への移行は、次の 3 つのステップで行います。

1.state セットをアクションのディスパッチに置き換える。
2.リデューサ関数を作成する。
3.コンポーネントからリデューサを使用する。

## state セットをアクションのディスパッチに置き換える。
イベントハンドラ関数を全て置き換えます。
※例は公式ページから。
改めて更新のプロセスを振り返られて良いです。

### 変更前
イベントハンドラに処理内容を記述
```react
function handleAddTask(text) {
  setTasks([
    ...tasks,
    {
      id: nextId++,
      text: text,
      done: false,
    },
  ]);
}

function handleChangeTask(task) {
  setTasks(
    tasks.map((t) => {
      if (t.id === task.id) {
        return task;
      } else {
        return t;
      }
    })
  );
}

function handleDeleteTask(taskId) {
  setTasks(tasks.filter((t) => t.id !== taskId));
}
```

### 変更後
dispatchに"action"というオブジェクトを渡します。
actionには「何が起こったか（**type**）」の最小限の情報を渡す。
```react
function handleAddTask(text) {
  dispatch({
    type: 'added',
    id: nextId++,
    text: text,
  });
}

function handleChangeTask(task) {
  dispatch({
    type: 'changed',
    task: task,
  });
}

function handleDeleteTask(taskId) {
  dispatch({
    type: 'deleted',
    id: taskId,
  });
}
```

## リデューサ関数を作成する 
reducerに渡す、更新用関数を作成します。
```react
/*
tasks = reducer初期化時に返却されるstate
action = 更新用関数に渡した引数（今回はdispatchの引数)
*/
function tasksReducer(tasks, action) {
  switch (action.type) {
    case 'added': {
      return [
        ...tasks,
        {
          id: action.id,
          text: action.text,
          done: false,
        },
      ];
    }
    case 'changed': {
      return tasks.map((t) => {
        if (t.id === action.task.id) {
          return action.task;
        } else {
          return t;
        }
      });
    }
    case 'deleted': {
      return tasks.filter((t) => t.id !== action.id);
    }
    default: {
      throw Error('Unknown action: ' + action.type);
    }
  }
}
```

## コンポーネントからリデューサを使用する 

```react
/* 
tasks = state値
dispatch = ディスパッチ関数（ユーザアクションをリデューサに「ディスパッチ」する）
tasksReducer = リデューサ関数
initialTasks = 初期state
*/
const [tasks, dispatch] = useReducer(tasksReducer, initialTasks);
```

・全体の流れは下記の通りです。
ボタンを押す。
→イベントハンドラが発火
→更新用関数（今回はdispacth（tasksReducer関数）にactionを渡し実行
→tasksReducer関数内で、action.typeに応じて更新処理を実行
→state(今回はtasks）の更新
```react
  return (
    <>
      <h1>Prague itinerary</h1>
      <AddTask onAddTask={handleAddTask} />
      <TaskList
        tasks={tasks}
        onChangeTask={handleChangeTask}
        onDeleteTask={handleDeleteTask}
      />
    </>
  );
```
