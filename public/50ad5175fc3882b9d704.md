# refとは
再レンダリングのトリガーにはしたくないが、レンダリング間で値を保持したい時に使用する。

## コンポーネントにrefを追加
refはcurrentプロパティを読み書きできるだけのプレーンなJavaScriptオブジェクト
```react
import { useRef } from 'react';

export default function Counter() {
  // 初期化
  let ref = useRef(0);

  function handleClick() {
    // 更新用関数のようにcurrentで現在の値を取得する
    ref.current = ref.current + 1;
    alert('You clicked ' + ref.current + ' times!');
  }

  return (
    <button onClick={handleClick}>
      Click me!
      {ref.current} {/*ここで表示してもレンダリング起きないため初期値である*/}
    </button>
  );
}
```

## refの使い方
```react
import { useState, useRef } from 'react';

export default function Stopwatch() {
  const [startTime, setStartTime] = useState(null);
  const [now, setNow] = useState(null);
  // インターバルIDをレンダリング間で保持するためrefにする
  const intervalRef = useRef(null);

  function handleStart() {
    // 時間部分の差分を出すため
    setStartTime(Date.now());
    // インターバル時間
    setNow(Date.now());

    clearInterval(intervalRef.current);
    intervalRef.current = setInterval(() => {
      setNow(Date.now());
    }, 10);
  }

  function handleStop() {
    // setIntervalの動作を取り消す
    clearInterval(intervalRef.current);
  }

  // レンダリングでstateの値を参照するためletで対応できる
  let secondsPassed = 0;
  if (startTime != null && now != null) {
    secondsPassed = (now - startTime) / 1000;
  }

  return (
    <>
      <h1>Time passed: {secondsPassed.toFixed(3)}</h1>
      <button onClick={handleStart}>
        Start
      </button>
      <button onClick={handleStop}>
        Stop
      </button>
    </>
  );
}

```

## refを使うタイミング
主にコンポーネントの外観に影響を与えないブラウザAPI
コンポーネントが値を保存する必要があるがそれがレンダーロジックに影響しない時、使用するため使う時は稀である。

## refを使用するときの原則
・refを非難ハッチとして扱う。頻繁に使うものではない。
・レンダリング中にref.currentを読み書きしない。
