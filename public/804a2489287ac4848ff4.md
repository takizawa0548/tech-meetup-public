# 初めてのコンポーネント

## コンポーネントとは何か
・マークアップはHTML、CSS、JavaScriptが組み合わさってUIができている。Reactでは再利用可能なUI要素にまとめたものをコンポーネントという。
ネスト関係は、レンダーツリーで表現できる。
・コンポーネントは純粋でなくてはいけない。（純関数）常に同じ入力には同じ結果。
Strict Modeは関数の問題にいち早く気づかせてくれる。（必ずしも開発メリットがあるわけではない。）

https://ja.react.dev/learn/keeping-components-pure

## マークアップの書き方
### 今までのWebページの作成方法
コンテンツをマークアップしてからJavaScriptを加える。
### Reactコンポーネント
マークアップを添えることができるJavaScript関数。一度書けば何度でも使える。細かい内容は省略。

# ルートコンポーネントファイル
基本的にはApp.jsのこと。（Next.jsの場合はページごとに異なるなど）

# コンポーネントのインポートとエクスポート
## インポート
コンポーネントをモジュール化し、他のファイルからも再利用可能とする。
デフォルトエクスポートと名前付きエクスポートは記述を分ける。
```react
import Test,{Test2,Test3} from './Test.js';
```
## エクスポート
### デフォルトエクスポート
ファイルに一つしか作れない
### 名前付きエクスポート
幾つでもおける

# JSX でマークアップを記述する
## JSXとは
JavaScriptファイル内にHTMLのようなマークアップをかけるようにするもの。JSの動作で表示されるものが決まるようになり、HTMLも一緒に書けることで関心ごとをまとめることができるようになった。
タグは一つにまとめて返す。（JavaScriptのオブジェクトとして一つにして返さなければいけないから）
閉じタグは必須。
属性名はキャメルケースで。
コンバータを使うのが便利。（AIに聞くのも・・・）

https://transform.tools/html-to-jsx

# JSX に波括弧で JavaScript を含める
下記の書き方でマークアップ内にJavaScriptへ書ける。属性内にも書ける。
属性内でもダブルクォーテーションで囲む（"{Text}")と文字列そのものを渡す。
```React
<div>{Text}<div/>
```
波括弧二つでCSSスタイルを使うことができる。
波括弧二つ目はオブジェクトの意味なので、変数でオブジェクトを渡すやり方でも実現可能。
```React
<ul style={{
      backgroundColor: 'black',
      color: 'pink'
    }}>
```

# Props
オブジェクトや配列、関数などのあらゆるJavaScriptの値を渡すことができる。
イメージタグ（<img>)のsrc属性もProps。
分割代入の中でデフォルト値を書くこともできる。デフォルト値がなくpropsにない場合は、undefinedになる。
```react
<Test obj={{A:'a', B:'b'}} num={100} str={"moji"}>

function Test({obj,num=1000,str}){
}
```

# 条件付きレンダー
論理演算子の右は真偽値にすること（数値にすると0の場合は0が表示される）
```react
// 三項演算子
{isTest ? (<div> {test} </div>) : (<div></div>)}: 
// 論理演算子
{isTest && <div>{test}</div>}
```

# リストのレンダー
## map
リスト内の値を一つずつ処理する。
```react
numbers.map(number => number * number);
```
## filter
条件で抽出する。
```react
numbers.filter(number => number % 2 === 0);
```
## keyの設定
レンダリングした時にどの要素が何を指すか示すためにkeyを設定する。
```react
const items = [
  { id: 1, text: 'アイテム1' },
  { id: 2, text: 'アイテム2' },
  { id: 3, text: 'アイテム3' },
];

function ItemList() {
  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>{item.text}</li>
      ))}
    </ul>
  );
}
```
