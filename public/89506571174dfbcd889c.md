# ReducerとContext
Reducerを使えばstate更新ロジックを集約することができ、Contextと組み合わせれば深い階層への情報連携が可能になる。

## Reducerによるバケツリレーの困難さ
stateでも言えることだが、stateやイベントハンドラ関数が増えて深い階層への受け渡しが発生するほど、製造の困難さが上がる。
回避策としては、contextを使う、カスタムフックを利用する手法が考えられる。

```react
export default function TaskApp() {
  const [tasks, dispatch] = useReducer(
    tasksReducer,
    initialTasks
  );
...
// トップレベルでのpropsの受け渡しのみならいいが、孫にまで伝播するとpropsの数が増える
<TaskList
tasks={tasks}
onChangeTask={handleChangeTask}
onDeleteTask={handleDeleteTask}
/>
```

# ReducerとContextを組み合わせる方法
手順は下記の通り
1.コンテクストを作成する。
2.state と dispatch をコンテクストに入れる。
3.ツリー内の任意の場所でコンテクストを使用する。

## コンテクストを作成する
Reducerのtasksとdispatch関数をcontextで定義する
```react
const [tasks, dispatch] = useReducer(tasksReducer, initialTasks);
```
別ファイルでcontextを定義する。
```react
import { createContext } from 'react';

export const TasksContext = createContext(null);
export const TasksDispatchContext = createContext(null);
```

## state と dispatch をコンテクストに入れる
最上階のコンポーネントでcontextをインポートして初期化し、providerを設定
```react
import { TasksContext, TasksDispatchContext } from './TasksContext.js';

export default function TaskApp() {
  const [tasks, dispatch] = useReducer(tasksReducer, initialTasks);
  // ...
  return (
    <TasksContext.Provider value={tasks}>
      <TasksDispatchContext.Provider value={dispatch}>
```

さらに上記の部分をcontextを定義したファイルで設定し、childrenをラップするコンポーネントを作成することで処理を簡潔に記述できる
```react
export function TasksProvider({ children }) {
  const [tasks, dispatch] = useReducer(tasksReducer, initialTasks);

  return (
    <TasksContext.Provider value={tasks}>
      <TasksDispatchContext.Provider value={dispatch}>
        {children}
      </TasksDispatchContext.Provider>
    </TasksContext.Provider>
  );
}
```
他にもcontextを定義したファイルに読み込みのためのuseContextを記述しエクスポートすることで関連ある操作などをまとめることができる
```react
export function useTasks() {
  return useContext(TasksContext);
}

export function useTasksDispatch() {
  return useContext(TasksDispatchContext);
}
```

## ツリー内の任意の場所でコンテクストを使う
下記の通りpropsが不要になる。
読み込み
```react
export default function TaskList() {
  const tasks = useContext(TasksContext);
```

更新
```react
export default function AddTask() {
  const [text, setText] = useState('');
  const dispatch = useContext(TasksDispatchContext);
  // ...
  return (
    // ...
    <button onClick={() => {
      setText('');
      dispatch({
        type: 'added',
        id: nextId++,
        text: text,
      });
    }}>Add</button>
```
