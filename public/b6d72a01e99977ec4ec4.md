# Reactプロジェクト作成
下記URLも参考にしました。

https://ja.legacy.reactjs.org/docs/create-a-new-react-app.html

プロジェクトを作りたいディレクトリに移動し下記のコマンドを実行します。my-appのところは自分の好きな名前にしましょう！
```
npx create-react-app my-app
```

メッセージが出ますが、続けるための同意なのでそのまま進めます。

# Node.jsバージョンの固定化
パッケージ配下に来ているので、Voltaでバージョンも固定化してみます。
```
volta pin node
```
![スクリーンショット 2024-02-18 13.40.35.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/6284e8b5-26ba-61ab-35ee-ef0bd1b78e4d.png)

package.jsonの中を確認してみると一番したに入ったのが確認できます。
```
 cat package.json
```
![スクリーンショット 2024-02-18 13.42.17.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/cffb607f-561f-6fc7-ae6a-c0f2785535f4.png)

# Reactアプリ起動！
プロジェクト配下で下記のコマンドを実行します。
```
npm start
```
Webブラウザ経由で<bold>http://localhost:3000/<bold/>にアクセスして、
下記の画面が表示されれば起動完了です！

![スクリーンショット 2024-02-18 13.48.54.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/b68bbeba-03b6-a53c-4e94-409cf25012a9.png)

停止させるときは、ターミナル上で「Control＋C」を押して停止させましょう。
