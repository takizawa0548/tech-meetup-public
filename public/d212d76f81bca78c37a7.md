# オブジェクトの種類
### readOnly
propertyへ再代入した時に警告することができます。実行エラーにはなりません。
```ts
type SomeType = {
  readonly prop: string;
}
 
function doSomething(obj: SomeType) {
  console.log(`prop has the value '${obj.prop}'.`);
 
  // 警告
  obj.prop = "hello";
  // helloは表示されます
  console.log(obj.prop)
}

const obj:SomeType = {
  prop:'test'
}

doSomething(obj)
```

### ReadonlyArray
pushプロパティを使用すると警告されます。
letを使用して上書きした場合は警告が出ないので注意。
```ts
const roArray: ReadonlyArray<string> = ["red", "green", "blue"];
// 警告
roArray.push('a');
```

### タプル型
配列の型をインデックス単位で指定できます。
```ts
type StringNumberBooleans = [string, number, ...boolean[]];
type StringBooleansNumber = [string, ...boolean[], number];
type BooleansStringNumber = [...boolean[], string, number];

const a: StringNumberBooleans = ["hello", 1];
const b: StringNumberBooleans = ["beautiful", 2, true];
const c: StringNumberBooleans = ["world", 3, true, false, true, false, true];
```

# 型操作
## ジェネリック
<>で型の注入が可能です。中の名称はType以外でも統一されていれば問題ありません。
```ts
function identity<Type>(arg: Type): Type {
  return arg;
}
// 返り値もstringで定義されます。
let output = identity<string>("myString");
```
### 引数の型とメソッド
Typeの場合でも呼び出せるプロパティを絞り込まないといけません。
```ts
function loggingIdentity<Type>(arg: Array<Type> | string): Array<Type> | string {
  console.log(arg.length); // Array has a .length, so no more error
  return arg;
}
```
### 定義部分の切り出し
下記のように切り出し、ジェネリックで型を定義する記述も可能です。
```ts
type GenericIdentityFn<Type> = {
  (arg: Type): Type;
}
 
function identity<Type>(arg: Type): Type {
  return arg;
}
 
let myIdentity: GenericIdentityFn<number> = identity;
```

### propertyによる制限
下記の例の場合は、propertyにlengthがないと警告されます。
```ts
type Lengthwise = {
  length: number;
}
 
function loggingIdentity<Type extends Lengthwise>(arg: Type): Type {
  console.log(arg.length); // Now we know it has a .length property, so no more error
  return arg;
}

loggingIdentity({ length: 10, value: 3 });
```

### keyofによる制限
```ts
function getProperty<Type, Key extends keyof Type>(obj: Type, key: Key) {
  return obj[key];
}
 
let x = { a: 1, b: 2, c: 3, d: 4 };
 
getProperty(x, "a");
// keyにない為警告
getProperty(x, "m");
```
