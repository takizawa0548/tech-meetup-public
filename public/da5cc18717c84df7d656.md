

# TypeScriptの動作保持とポイント
・TypeScriptはJavaScriptで書いたコードの動作をTypeScriptエラーが出ても動作できるようにしている。
・TypeScriptはコンパイル時の型チェッカーを備えたJavaScriptのランタイムである。
・TypeScriptの型チェックは形状に焦点を当てている（ダックタイピング）

# 型推論

```typescript
let helloWorld = "Hello World";
```

## 型定義

オブジェクトに対する型定義配下のように行います。

JavaScript
```javascript
const user = {
  name: "Hayes",
  id: 0,
};
```
typeScript
```typescript
interface User {
  name: string;
  id: number;
}
//または
type User = {
  name: string;
  id: number;
}

const user: User = {
  name: "Hayes",
  id: 0,
};
```

下記のようにidにstringを定義するとエラーが発生する。
```typescript
const user: User = {
  name: "Hayes",
  id: "0",
};
// Type 'string' is not assignable to type 'number'.
```

interfaceまたはtypeを指定することにより、引数や戻り値に型指定ができる
```typescript
function deleteUser(user: User) {
  // ...
}
 
function getAdminUser(): User {
  //...
}
```

## タイプの合成

### ユニオン
受け取れる値を制限する
```typescript
type WindowStates = "open" | "closed" | "minimized";
type LockStates = "locked" | "unlocked";
type PositiveOddNumbersUnderTen = 1 | 3 | 5 | 7 | 9;

// WindowStatesに書いたもの以外はエラー
const a:WindowStates="open"
```

受け取れる型を複数定義
```typescript
function getLength(obj: string | string[]) {
  return obj.length;
}
```
