#### サーバーサイド認証
今回はクイックスタートなのでクライアントサイドで認証を通しますが、情報の書き換えも可能になってしまうため基本的にNG。
サーバーサイドで認証できるようにする必要があります。認証情報を渡して、ルーム情報を返すことになりそう。
下記のサンプルは認証情報を返すところまで書いてありました。

https://github.com/skyway/authentication-samples

```js
(async () => {
  const localVideo = document.getElementById('local-video');
  const { audio, video } = await SkyWayStreamFactory.createMicrophoneAudioAndCameraStream();
  video.attach(localVideo);
  await localVideo.play();
})();
```
:point_up:
SkyWayStreamFactory.createMicrophoneAudioAndCameraStream() 関数を呼び出して、デバイスのマイクとカメラからオーディオとビデオのストリームを生成しビデオをアタッチして再生しています。
video.attach(localVideo)の読み方は覚えておきたいです。
今回は「videoストリームをlocalVideo要素にアタッチする」という意味です。
また、localVideo.play()をやっている通り、タグはVideoである必要があります。
ここに修正したビデオを差し込めるという意味だとも思っています。

```js
const context = await SkyWayContext.Create(token);
```   
:point_up:SkyWay Auth Tokenで生成した乱数のようなトークンからアプリケーションの設定を行なっています。SkyWay Auth Tokenはサーバーサイドでも取得できるのでそちらが推奨されている。

https://javascript-sdk.api-reference.skyway.ntt.com/room/#md:skywaycontext

```js
      const room = await SkyWayRoom.FindOrCreate(context, {
        type: 'p2p',
        name: roomNameInput.value,
      });
      const me = await room.join();
```
:point_up:p2pで通信し、入力した値で部屋を作って参加しています。room.join()の引数にはname(一意）とmetadataの設定が可能。

```js
await me.publish(audio);
await me.publish(video);
```
:point_up:ストリームをroom内で公開しています。

```js
room.publications.forEach(subscribeAndAttach);
room.onStreamPublished.add((e) => subscribeAndAttach(e.publication));
```
:point_up:publicationsは現在公開しているストリームを要素として生成し、onStreamPublishedに新しい公開ストリームがあれば追加するイベントがあれば、公開ストリームを引数に渡して要素を生成します。

```js

```
:point_up:生成部分です。videoタグやaudioタグにストリームを入れて表現しています。
