# refが必要な場面
Reactが管理するDOM要素へのアクセスやReact外部の情報の格納
ノード情報が欲しい場合は、レンダー中（コンポーネント呼び出し中）ではなくコミット中（DOMが作成され変更されている時）に呼び出す。
(一例）
・ノードにフォーカスを当てる
・スクロールさせる
・サイズや位置を測定する
・タイマー管理

DOMノードの変更や削除はしないこと。Reactが管理できないため。

詳しくは下記の内容

https://developer.mozilla.org/ja/docs/Web/API/Element

# DOMノードへのアクセスを取得
```react
import { useRef } from 'react'
...
const myRef = useRef(null);
...
//この時点でmyRef.currentにdivに対応するDOMノードが作成される
return(
<div ref={myRef}>
)
```

# 例：focus
対象のDOMノードにフォーカス
```react
function handleClick() {
    inputRef.current.focus();
}
```

# 例：scroll
対象のDOMノードにスクロール
behavior：スクロールの動作について（smootmは スクロールをスムーズなアニメーションで行う）
block：垂直方向でブラウザのどこに表示するか（startなら上部、endなら下部、nearestなら一番近いところ）
inline：水平方向でブラウザのどこに表示するか

詳細

https://developer.mozilla.org/ja/docs/Web/API/Element/scrollIntoView

```react
function handleScrollToSecondCat() {
    secondCatRef.current.scrollIntoView({
      behavior: 'smooth',
      block: 'nearest',
      inline: 'center'
    });
}
```

idに沿ってnodeを取得する。
```react
function scrollToId(itemId) {
    const map = getMap()
    const node = map.get(itemId);
    node.scrollIntoView({
```

# 別のコンポーネントにアクセスするには
下記の例だと、nullが返されてしまう可能性がある。これはReactが意図的にそうしている。
```react
<MyInput ref={inputRef} />
```

コンポーネント側で明示的にrefを受け取ることを記述することが必要である。forwardRefでラップし、props({})の後に記述することがルール。CSSのスタイルを変更するは基本的でないので、操作を制限したい場合は、useImperativeHandleを使用する。
```react
const MyInput = forwardRef((props, ref) => {
  return <input {...props} ref={ref} />;
});
```

# 同期的にDOMを更新
イベントハンドラ内に下記の記載をすると、末尾が更新される前の位置にスクロールされる
```react
setTodos([ ...todos, newTodo]);
listRef.current.lastChild.scrollIntoView();
```
更新後の末尾にスクロールしたい場合はフラッシュする
```react
flushSync(() => {
  setTodos([ ...todos, newTodo]);
});
listRef.current.lastChild.scrollIntoView();
```
