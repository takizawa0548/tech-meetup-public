# stateの保持と破棄
Reactは**各コンポーネントごとにStateが保持され、レンダーツリーに沿ってstateを管理**します。
コンポーネントが破棄されるとstateも破棄されます。
ただし、**レンダリング時に同様なコンポーネントがあると判定された場合、stateは保持**されることがあります。
# stateが保持されるパターン

#### 1.別々に記述していても保持されるパターン
**同様なコンポーネントとみなされstateは保持**されます。

```react
{isFancy ? (
    <Counter isFancy={true} /> 
) : (
    <Counter isFancy={false} /> 
)}
```

#### 2.構造が同じであるため保持されるパターン
リターン位置が違う場合も、**構造が同じであればstateは保持**されます。
```react
if (isFancy) {
    return (
      <div>
        <Counter isFancy={true} />
      </div>
    );
} else {
  return (
    <div>
      <Counter isFancy={false} />
    </div>
  );
}
```

# stateが破棄されるパターン
#### 1.条件付きレンダリングの記述をわける
条件付きレンダリングを別々に記述すると、**レンダリング処理が個別に行われ破棄**されます。
```react
 <div>
      {isPlayerA &&
        <Counter person="Taylor" />
      }
      {!isPlayerA &&
        <Counter person="Sarah" />
      }
</div>
```

#### 2.構造を変える
**構造が違うとstateは破棄**されます。
```react
{isFancy ? (
 <div>
    <Counter isFancy={true} /> 
 </div>
) : (
    <Counter isFancy={false} /> 
)}
```

#### ３.keyを使って各コンポーネントに明示的な識別子を付与する
同様な構成でもコンポーネントの**keyが違うとstateを破棄**します。

```react
  return (
    <div>
      {isPlayerA ? (
        <Counter key="Taylor" person="Taylor" />
      ) : (
        <Counter key="Sarah" person="Sarah" />
      )}
```
