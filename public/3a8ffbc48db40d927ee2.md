# クイックスタート
## はじめに（GitHub Actionsとは）
GitHubが提供するCI/CD（継続的インテグレーション／継続的デリバリー）ツールです。これにより、リポジトリの変更に対して自動化されたワークフロー（ビルド、テスト、デプロイメントなど）を設定することができます。

## 最初のワークフローを作成する
新しいレポジトリを作成。Actionsタブからsetupを始めます。

## ワークフローの結果を表示する
ファイル作成後、実行された内容を確認しましょう。

# GitHub Actionsについて
## サンプルワークフローを作成する ワークフローファイルを理解する
```yml
name: learn-github-actions
run-name: ${{ github.actor }} is learning GitHub Actions
on: [push]
jobs:
  check-bats-version:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm install -g bats
      - run: bats -v
```

GitHub リポジトリの 「Actions」 タブに表示されるワークフロー名
```yml
name: learn-github-actions
```

ワークフロー実行中、表示されるメッセージ
```yml
run-name: ${{ github.actor }} is learning GitHub Actions
```
![スクリーンショット 2024-06-14 20.21.54.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/943982/0b9bd683-2658-2d37-6517-e293cf5e7cc6.png)

ワークフローのトリガー。今回はPushがトリガーとなる。
```yml
on: [push]
```

ジョブのグループ化
```yml
jobs:
```
ジョブを定義
```yml
check-bats-version：
```

ubuntu-latest（最新版の Ubuntu Linux）で実行するように設定
```yml
runs-on: ubuntu-latest
```
すべてのステップをグループ化。入れ子になっているのはアクションかスクリプト
```yml
steps:
```
actions/checkout アクションはワークフローでリポジトリのコードを使用するときに使う。
```yml
- uses: actions/checkout@v4
```
Node.jsのバージョンを指定してインストール
```yml
- uses: actions/setup-node@v4
        with:
          node-version: '20'
```
コマンドを実行するようジョブに指示
```yml
 - run: npm install -g bats
```
batsコマンドを実行
```yml
- run: bats -v
```
