### Non-null Assertion Operator (Postfix !)
nullまたはundefinedである可能性を無視します。
明らかにnullまたはundefinedが来ないことを前提に対応します。
```ts
function liveDangerously(x?: number | null) {
  // 実行してnullがくるとエラー
  console.log(x!.toFixed());
}
```

# Narrowing

### typeof type guards
unionTypeなどで複数の型が想定される場合、呼び出せるメソッドに影響します。
その時にtypeofで型を狭める方法をtypeod type guards(型ガード）と言います。
また宣言された型を具体的な型に狭めていくプロセスをNarrowingと言います
```ts
typeof padding === "number"
```

### objectのtypeof
objectのtypeofはnullも含みます。注意しましょう。
下記の場合、typeofでobjectに狭めても、「strs」のtypeは「string[] | null」で、nullが残ります。
```ts
function printAll(strs: string | string[] | null) {
  if (typeof strs === "object") {
    for (const s of strs) {
      console.log(s);
    }
  }...
}
```
対応策としては、「truthy」であることを判定してから狭める方法です。
下記の場合、「strs」が「truthy」であることを条件にしたため、「null」は無くなります。
```ts
function printAll(strs: string | string[] | null) {
  if (strs && typeof strs === "object") {
    for (const s of strs) {
      console.log(s);
    }
  }
}
```
#### truthyとfalthy
値をtrueまたはfalseと同等に扱うことです。
下記の場合、falthy扱いになります。
```
0
NaN
""(空の文字列)
0n（bigintゼロバージョン）
null
undefined
```
if文で判定することが可能です。空の文字列を扱いたい場合も同様にfalthyです。そこは留意しましょう。
```ts
// strsがfalthyのいずれかならif文内には入らない
if (strs && typeof strs === "object") {
  ...
}
```

### 平等による推測
下記のif文の場合、xとyが同等となる型はstringのみなのでTypeScriptが推測してstringにします。
```ts
function example(x: string | number, y: string | boolean) {
  if (x === y) {
    // We can now call any 'string' method on 'x' or 'y'.
    x.toUpperCase();
    y.toLowerCase();         
  }
}
```
